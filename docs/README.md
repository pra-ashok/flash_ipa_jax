# Documentation

The repository [README](../README.md) indexes every guide, executable example,
and development entry point. Start here for a guided reading order:

1. [Concepts](CONCEPTS.md): what IPA computes, where it helps and why JAX.
2. [Architecture](architecture.md): generated diagrams, model stages and source map.
3. [Usage](USAGE.md): layers, the complete structure model, shapes and masks.
4. [Training](TRAINING.md): optimizer loops, losses and dimension choices.
5. [Backends](BACKENDS.md): native, NVIDIA, AMD, XLA and TPU behavior.
6. [Kernel integration](KERNEL_INTEGRATION.md): attention equations and extension boundaries.
7. [Upstream coverage](UPSTREAM.md): what was ported and deliberate differences.
8. [References](REFERENCES.md): primary papers and implementation sources.

[Executable examples](../examples/README.md) provide runnable layer and model
training commands. The [validation record](../VALIDATION.md) distinguishes
executed CPU checks from tests requiring actual accelerators.
